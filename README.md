# Python Bank Management System

A command-line Bank Account Management System developed using Python.

## Features
- Create and delete accounts
- Deposit and withdraw funds
- PIN verification and PIN changes
- Account information display
- JSON-based data persistence
- Activity logging
- Object-Oriented Programming

## Technologies Used
- Python
- JSON
- Logging
- Object-Oriented Programming (OOP)

## Purpose
This project was developed as a learning project to practise Python OOP, file handling, data management and exception handling.

## Disclaimer
This is an educational simulation, not a real banking application. It is not suitable for storing real financial information or credentials.
